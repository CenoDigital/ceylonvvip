# @ceylonvvip/tokens

Design tokens from the Figma file `bIUkCC5TtQezAqa4RwLPI3` (Primitives and Theme collections, Outfit text styles, motion spec).

- `src/tokens.css`: CSS variables, imported once by each app's global stylesheet.
- `src/tokens.ts`: the same values for TypeScript (GSAP timings, charts, tests).

Figma is the source of truth. Change a token in Figma first, then re-export both files here.
